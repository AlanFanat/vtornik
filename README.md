# Оценщик дней

Flutter-приложение: оценка каждого дня от 1 до 10, теги и заметка. Данные хранятся на устройстве, есть тёмная тема и резервная копия через буфер обмена.

> Замените название и описание на свои.

## Запуск

```bash
flutter pub get
flutter run
```

Зависимости: `shared_preferences`.

## Как устроены данные

- Все записи лежат в `SharedPreferences` одной JSON-строкой: `{"2026-10-14": {"rating": 8, "tags": ["Работа"], "note": "..."}}`.
- Общий список тегов хранится отдельно. Переименование или удаление тега меняет его во всех прошлых днях.
- Редактор дня сохраняет сам: оценку и теги сразу, заметку через 400 мс после последнего символа.
- Если сохранённые данные не читаются, копия откладывается в ключ `entries_corrupted`, данные не теряются молча.
